신인과 OST 가창자 발굴은 지금 사람이 해요. 인스타그램 DM, 광고, 공연장 방문으로요. 성공한 아티스트의 초기 신호와 비슷하게 움직이는 아티스트를 먼저 찾는 쪽으로 넓혀 가요.

담당자 옆에서,
지난달 실제 자료로

회사 안에 깊이 들어가서, 거기서 생긴 문제를 직접 푸는 방식(FDE)이에요.

  1. 실무 흐름을 바닥까지 봐요

    담당자 옆에서 실제 파일과 화면으로 봐요.

  2. 사람이 손대던 단계 하나를 골라요

    고르는 건 회사예요.

  3. 지난달 실제 자료로 돌려 봐요

    사람 결과와 나란히 놓고 비교해요.

  4. 효과가 확인되면 다음 업무로 넓혀요

    정산에서 시작했으면 검수로, 검수에서 시작했으면 신호 알림으로요.
